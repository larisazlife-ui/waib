# Маршрут нового продукта

Внутреннее веб-приложение (stage-gate) для вывода новых продуктов через подразделения компании.
Требования — в [PRD.md](PRD.md). Код — исходники MVP, опубликованного как артефакт, разложенные по модулям, плюс доработки релиза 1.1.

## Запуск

Сборка и установка не нужны: чистые HTML, CSS и JavaScript.

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Затем откройте http://localhost:8080/ . Тесты: http://localhost:8080/tests/tests.html .
Другой порт: `serve.ps1 -Port 9000`. Подойдёт и любой другой статический сервер.

## Публикация

Опубликованная версия: https://claude.ai/artifact/37QvPYEUV6LgecddVT6yK8

Артефакт — это один HTML-файл. Его собирает скрипт:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат — `dist/marshrut-novogo-produkta.html`: стили и скрипты встроены, порядок скриптов берётся из `index.html`. В артефакте браузер блокирует скачивание файлов, поэтому кнопка «Скачать файл» там скрыта, а резервная копия JSON переносится через «Скопировать».

## Что нового относительно MVP (релиз 1.1)

- **Подсветка незаполненного.** Обязательные поля и пункты чек-листа, которых не хватает для согласования, выделяются. Список недостающего состоит из кнопок: клик переводит к полю, а для финального этапа — к несогласованному этапу.
- **Выгрузка и загрузка JSON.** Кнопки «Выгрузить» и «Загрузить» в шапке. Пока общее хранилище не подключено, так можно сделать резервную копию или передать продукты коллеге. Загрузка проверяет структуру и пропускает чужие файлы.
- Правила вынесены в отдельные функции (`missing`, `revokeFrom`, `parseComps`) и покрыты тестами.

## Тестовые данные

Кнопка «Тестовые данные» в шапке или на стартовом экране добавляет шесть условных продуктов из `js/fixtures.js`. Ваши продукты при этом не затрагиваются. Если нажать кнопку повторно, тестовые продукты заменятся свежей копией, а устаревшие тестовые продукты удалятся.

| Продукт | Карта | Что проверяет |
|---|---|---|
| Аннуитет «Надёжная опора» | Аннуитет, все 14 этапов | Полный маршрут, все контрольные точки в норме, штамп «Готов к запуску», сохранённая проверка Claude |
| Аннуитет «Гарант-Плюс» | Аннуитет, без перестрахования | Правление с 6 отклонениями: без комментария о принятии риска согласовать нельзя |
| Досрочный аннуитет «Досрочный старт» | Аннуитет, без аудита | Возврат на доработку, блокировка следующих этапов, подсветка недостающего |
| ОСНС «Безопасный труд» | ОСНС, все 13 этапов | Полный маршрут, комбинированный коэффициент 77%, все 10 контрольных точек в норме |
| ОСНС «Горнодобыча» | ОСНС | Юридическая экспертиза в работе: тариф выше предела и рынка, комбинированный коэффициент 112%, убыток от события 14% капитала, срок выплаты дольше предельного |
| Накопительное «Капитал 10» | Накопительное, без аудита | Полный маршрут, доходность для клиента в рыночном коридоре, все 11 контрольных точек в норме |

Все компании, люди, цифры и номера документов выдуманы. Предельный тариф ОСНС, предельный срок выплаты и предельная техническая ставка в тестовых данных — условные значения: настоящие вносит юридический департамент по действующим редакциям.

Карта «Производство товара» удалена. Продукты, созданные по ней раньше, не показываются, но остаются в хранилище браузера и попадают в выгрузку JSON.

## Режимы хранения

- **Локальный** (по умолчанию): данные в `localStorage` браузера, у каждого пользователя свои.
- **Общий**: если страница опубликована как артефакт Claude с возможностями `db`, `user` и `sample`, `js/main.js` подключает общую базу, имена согласующих и кнопку «Проверить этап». Код для этого уже есть, нужно только выдать возможности при публикации.

## Как добавить технологическую карту

1. Создайте `js/templates/<id>.js` по образцу существующих: `stages` (поля, чек-листы, флаги `comps`, `econ`, `gates`, `opt`), `calc`, `gates`, `figs`, `side`, `head`, `demo`.
2. Добавьте карту в `TPL` в `js/templates/index.js` и подключите файл в `index.html` и `tests/tests.html`.

> Ссылки на нормативные акты в чек-листах и все цифры в примерах условные. Их должен подтвердить юридический департамент.
